# Czcionki do PDF-ów

`NewCMMono10-Regular.otf` i `NewCMMono10-Bold.otf` to New Computer Modern Mono 7.1.1, krój maszynowy w stylu LaTeX-a. Typst ma wbudowaną tylko szeryfową New Computer Modern, dlatego krój do kodu jest tutaj. `scripts/build-docs.sh` podaje ten folder Typstowi przez `--font-path`.
